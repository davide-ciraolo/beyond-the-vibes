# Skills

## make-slides

The project Skill used to build the "Beyond the Vibes" slide decks, and shown in Module 5 as a worked example of a Skill.

- `SKILL.md`: when the Skill fires and the steps it follows
- `layouts.md`: the approved slide layouts and their options
- `templates/`: one example slide per layout

It was written for the course's working repository and refers to files that aren't published here: the Slidev theme (`slides/theme/`), the slide linter (`tools/check_slides.py`) and the module outlines (`docs/framework/`). Read it as an example of how to structure a Skill. To use it in your own project, copy the folder to `.claude/skills/make-slides/` and change those paths.
