## The dividing line is *review and accountability*, not the tool

::left::

### Vibe coding
- Accept All, don't read diffs
- Paste errors back
- No tests
- Fine for throwaway projects

::right::

### Agentic engineering
- Read every diff
- Tests are the feedback loop
- Plan first, own the result
- Fit for production

::bottom::

Same agent, either mode.
