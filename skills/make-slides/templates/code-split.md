## A Skill is a folder with a *SKILL&#46;md*

::left::

```markdown
---
name: make-slides
description: Use when creating or editing
  slides for this course…
---
# Make Slides
1. Copy a template for the layout
2. One idea per slide
```

::right::

1. Loaded only when the description matches
2. Can bundle templates and references
3. Shareable through plugins
